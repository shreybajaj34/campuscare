Google Sheets Backend Integration

CampusCare is built to store all Admin credentials, Students, and Complaints in a Google Sheet via Google Apps Script without needing any paid server.

Leave blank to run in Browser LocalStorage mode (ready for instant testing).

3-Minute Setup Instructions for Google Sheet

  1. Go to sheets.new and create a new sheet named CampusCare_Database.
  2. In the menu, open Extensions > Apps Script.
  3. Delete any default code and paste the code from google-apps-script/Code.gs.
  4. Click Deploy > New deployment.
  5. Select type Web app. Set Execute as: Me and Who has access: Anyone.
  6. Click Deploy, copy the generated Web App URL, and paste it into the box above!
